## ✨ Key Features (ප්‍රධාන විශේෂාංග)

### 1. 🏛️ 4-Level Academic Hierarchy (අධ්‍යයන ව්‍යුහය)
* **Faculty (පීඨය)** $\rightarrow$ **Academic Year (1st - 4th Year)** $\rightarrow$ **Semester (1st & 2nd Semester)** $\rightarrow$ **Subjects (විෂයන්)** $\rightarrow$ **Modules/Notes**
* සෑම මට්ටමකම නම වෙනස් කිරීම (**Edit**) සහ මකා දැමීම (**Delete**) පහසුවෙන්ම සිදු කළ හැක.

### 2. 📁 7 Dynamic Note Categories
* **සිලබස් (Syllabus)**
* **කෙටි සටහන් (Short Notes)**
* **ප්‍රසන්ටේෂන් (Presentations)**
* **අගයීම් (Assignments)**
* **මැද සෙමෙස්ටර් විභාග (Mid Exams)**
* **පාස් පේපර්ස් (Past Papers)**
* **කියවන පොත්පත් (Recommended Books Tracker)**

### 3. 📖 Recommended Book Tracker (පුස්තකාල පොත් පරිශීලකය)
