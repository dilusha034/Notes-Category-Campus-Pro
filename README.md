## 🌟 Overview (හැඳින්වීම)

**Notes Category** යනු විශ්වවිද්‍යාල සහ උසස් අධ්‍යාපන ශිෂ්‍ය ශිෂ්‍යාවන්ගේ අධ්‍යයන කටයුතු (Lectures, Short Notes, Syllabuses, Books, Assignments & Mid Exams) ඉතාම විධිමත්ව, ලස්සනට සහ කාර්යක්ෂමව පවත්වාගෙන යාම සඳහා නිර්මාණය කරන ලද **Cyber Glassmorphic Web & Windows Desktop Application** එකකි.

## ✨ Key Features (ප්‍රධාන විශේෂාංග)

### 1. 🏛️ 4-Level Academic Hierarchy (අධ්‍යයන ව්‍යුහය)
* **Faculty (පීඨය)** $\rightarrow$ **Academic Year (1st - 4th Year)** $\rightarrow$ **Semester (1st & 2nd Semester)** $\rightarrow$ **Subjects (විෂයන්)** $\rightarrow$ **Modules/Notes**
* සෑම මට්ටමකම නම වෙනස් කිරීම (**Edit**) සහ මකා දැමීම (**Delete**) පහසුවෙන්ම සිදු කළ හැක.

### 2. 📁 7 Dynamic Note Categories
* **සිලබස් (Syllabus)**
* **කෙටි සටහන් (Short Notes)**
* **ප්‍රසන්ටේෂන් (Presentations)**
* **අගයීම් (Assignments)**
* **මැද සෙමෙස්ටර් விභාග (Mid Exams)**
* **පාස් පේපර්ස් (Past Papers)**
* **කියවන පොත්පත් (Recommended Books Tracker)**

### 3. 📖 Recommended Book Tracker (පුස්තකාල පොත් පරිශීලකය)
* කර්තෘගේ නම, ප්‍රකාශකයන්, සහ පුස්තකාල ID අංකය සටහන් කිරීම.
* **Current Page Quick Counter (`+` / `-`):** තමන් දැනට කියවන පිටු අංකය ක්ෂණිකව එක ක්ලික් එකෙන් Update කරගැනීමේ හැකියාව.

### 4. 📸 Photo & Image Attachments
* නෝට්ස් සහ කෙටි සටහන් සකස් කිරීමේදී Diagrams, පාඩම් සටහන් ඡායාරූප හෝ Image Links සටහන තුළටම Upload කර එකතු කරගැනීමේ හැකියාව.

### 5. 🔍 Distraction-Free Full-Screen Note Reader
* දීර්ඝ සටහන් කියවීමේදී බාධා කිරීම් රහිතව (Distraction-free) මුළු Screen එක පුරාම පැහැදිලිව තබාගෙන කියවීමේ පහසුකම.

### 6. 📄 Share & PDF Export
* තමන් සකස් කරගත් සටහන් හෝ මුළු විෂයයම එක ක්ලික් එකෙන් **Print / PDF** ගොනුවක් ලෙස Download කර යහළුවන් අතර Share කරගැනීමේ පහසුකම.

### 7. 📅 Interactive Timetable (ශිෂ්‍ය කාලසටහන)
* සතියේ දින 7 සඳහාම Lectures, Tutorials සහ Extra Classes කාලසටහන්ගත කිරීම, සංස්කරණය (**Edit**) සහ කළමනාකරණය.

## 💻 How to Run / Build on Windows 11 (භාවිතා කරන ආකාරය)

### Option A: Open in Browser (බ්‍රවුසරයෙන් සෘජුවම)
1. `index.html` ගොනුව ඕනෑම බ්‍රවුසරයකින් (Brave, Chrome, Edge) Open කර භාවිතා කරන්න.
2. නැතහොත් Local Web Server එකක් මගින් `http://localhost:8080` ඔස්සේ භාවිතා කරන්න.

### Option B: Windows Desktop App (Executable Software එකක් ලෙස)
1. පරිගණකයේ `Node.js` ස්ථාපනය කර තිබිය යුතුය.
2. Project folder එක තුළ Terminal/Command Prompt එකක් Open කර පහත Command එක ක්‍රියාත්මක කරන්න:
```bash
npm install
npm start
```
3. Windows `.exe` Installer එකක් සකස් කරගැනීමට:
```bash
npm run build-win
```
